# 여기는 마법소녀 구명외과 한글 패치 v1.0

**번역 : 컬리비(curlyB)**

[Magical Girl ER](https://store.steampowered.com/app/4395870/) Steam판 Ver.1.0.6을 기준으로 제작했습니다.

## 한글화 내용

- 대사, 메뉴, 인물 소개, 치료 안내 및 엔딩 번역.
- 등장인물의 이름·호칭·말투 통일.
- 원작 분위기에 맞춘 고운바탕·나눔손글씨 펜 글꼴 적용.
- 활동 허가증, 치료 안내서, 튜토리얼과 타이틀 로고 한글화.
- 인게임 제작진 크레딧에 번역자 표기 추가.

## 설치

1. 게임을 종료하고 ZIP을 풉니다.
2. `KoreanPatch` 폴더를 `Magical Girl ER.exe`가 있는 게임 설치 폴더에 넣습니다.
3. `KoreanPatch/InstallKoreanPatch.cmd`를 실행합니다.

게임은 한국어로 시작합니다. 별도의 Python 설치는 필요하지 않습니다.
설치 시 게임 버전으로 차단하지 않습니다. `CheckCompatibility.cmd`는 파일을 바꾸지 않고 패치 파일의 손상 여부만 확인합니다. 앞으로의 모든 게임 업데이트와 호환된다는 뜻은 아닙니다.

## 복원

`RestoreKoreanPatch.cmd`를 실행하면 가장 최근 패치 설치 직전 상태로 돌아갑니다. 백업은 게임 폴더의 `KoreanPatchBackup`에 저장됩니다. 이미 패치된 상태에서 재설치했다면 해당 패치 상태로 복원됩니다.

게임이 업데이트된 뒤에는 이전 백업을 덮어쓰지 말고 Steam 무결성 확인을 이용하세요. 설치·복원은 저장 데이터를 수정하지 않습니다.

## 알려진 현상

테스트 환경에서 종료 버튼을 누르면 Unity 오류 창이 나타났습니다. 한글패치를 적용하지 않은 원본에서도 동일하게 발생했습니다.

글꼴 라이선스는 `licenses` 폴더에 있습니다.
